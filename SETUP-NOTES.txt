IMPORTANT MERGE NOTES
1. This is a starter overlay, not a full Laravel installation. Run composer create-project first.
2. Run php artisan install:api on Laravel 11/12 to install Sanctum and create routes/api.php if needed.
3. If the command created routes/api.php, replace it with this starter's routes/api.php.
4. Laravel migration filenames must be timestamped and their ordering matters. The students migration references users, so ensure the default users migration runs before the students migration. If necessary, rename the students migration timestamp so it runs after the default create_users_table migration.
5. Merge HasApiTokens into the Laravel-generated app/Models/User.php if your generated version has additional code you want to keep.
6. StudentPolicy follows Laravel's conventional policy discovery (App\\Models\\Student => App\\Policies\\StudentPolicy). If your Laravel version does not discover it automatically, register it in your AuthServiceProvider.
7. For this starter, use Laravel 11/12 style. Older Laravel versions may need route/API setup adjustments.
